# 脚本规则工作台 — 需求文档

> 版本：v1.0（由 PRD v0.2 拆分而来，需求结论无变化）
> 日期：2026-09-01
> 关联文档：《技术方案》（同目录，文件名含"技术方案"）

## 1. 背景与目标

决策引擎的规则使用 Groovy 脚本编写。目前写规则、验规则、试规则缺少顺手的工具。
本项目做一个 **Web 版"脚本规则工作台"**，解决三件事：

1. **写**：提供脚本编辑器，支持 AI 对话辅助编写
2. **验**：一键校验脚本（语法校验 + 提取占位符 + 大模型审查语义问题）
3. **跑**：给占位符填值，真实执行脚本，查看返回值

## 2. 范围与边界

| 项 | 说明 |
|---|---|
| 脚本语言 | **仅 Groovy**（Python 不做） |
| 占位符语法 | `${变量名}`，例如 `${age}` |
| 用户体系 | 无，单用户工具，不做登录权限 |
| 部署形态 | 前后端分离开发，本机运行为主 |

## 3. 术语

- **规则**：一段 Groovy 脚本，决策引擎的最小执行单元，有返回值
- **占位符**：脚本中用 `${变量名}` 标记的输入变量，运行前需赋值
- **会话**：与 AI 大模型的一次对话（有独立记忆），一条规则固定对应一个会话
- **测试用例**：一组占位符填值的快照，可保存、可一键回填重跑

## 4. 页面与功能

### 4.1 页面结构总览

```
规则列表页 ──点击规则──▶ 规则工作台页（编辑 + 校验 + 运行 + AI 对话）
```

### 4.2 规则列表页

| 功能 | 说明 |
|---|---|
| 列表展示 | 表格：规则名称、描述、更新时间、操作 |
| 新建规则 | 弹窗填名称 + 描述，创建后跳转工作台 |
| 改名/改描述 | 列表页只改名称和描述；改脚本要进工作台 |
| 删除 | 二次确认，级联删除其会话、消息、测试用例 |
| 搜索 | 按规则名称模糊搜索 |
| 分页 | 简单分页即可 |

### 4.3 规则工作台页

**页面布局**（文字版线框，UI 细节可继续脑暴）：

```
┌──────────────────────────────────────────────┐
│ 规则名称                          [校验] [运行] │
├───────────────────────────┬──────────────────┤
│                           │                  │
│      脚本编辑器            │   AI 对话面板     │
│   （Groovy 语法高亮）      │   （单会话）      │
│                           │                  │
├───────────────────────────┤                  │
│ 校验结果区 / 占位符填值区    │                  │
│ / 运行结果区（标签页切换）    │                  │
└───────────────────────────┴──────────────────┘
```

#### 4.3.1 脚本编辑

- 编辑器带 Groovy 语法高亮、行号
- 脚本内容需手动保存（保存按钮 / Ctrl+S），保存即更新规则列表中的数据
- **注意**：校验、运行、AI 对话、AI 审查，用的都是**编辑器里的当前内容**（含未保存的修改），不是已保存版本

#### 4.3.2 校验（核心流程，同步）

两个按钮：**[校验]** 和 **[运行]**。规则：**必须校验全部完成且语法通过，运行按钮才可点击**。

点击 [校验] 后依次发生（**全部同步等待完成后才返回**）：

1. **语法校验**（毫秒级）
   - 失败 → 立即返回错误**行号 + 原因**，编辑器中该行标红，运行按钮保持锁定
2. **提取占位符列表**（毫秒级）
   - 从脚本中识别所有 `${变量名}`，并根据变量声明语句解析出类型（`int`/`long`/`double`/`boolean`/`String` 等）
3. **大模型 CR**（同步等待，约数秒到十几秒，前端展示"AI 审查中…"加载状态）
   - 把脚本发给大模型审查：语义错误、逻辑漏洞、潜在空指针等
   - 结果展示为"AI 审查"卡片
   - 若大模型给出修改后的完整脚本，卡片上提供 **[应用到编辑器]** 一键替换
4. **返回并解锁运行**
   - 语法通过 → 解锁运行按钮，同时展示占位符列表和 AI 审查卡片
   - **说明**：CR 是建议性质，即使 CR 指出问题也不强制阻断运行，只要语法通过 + CR 已返回即解锁

#### 4.3.3 运行

- 校验通过后，下方出现**占位符填值表单**，按类型渲染控件：
  - `int` / `long` / `double` → 数字输入框，前端校验格式
  - `boolean` → true/false 下拉
  - `String` → 文本框
  - 前端校验不通过不允许提交
- 点击 [运行] → 执行脚本 → 展示**返回值**
- 执行超过 **5 秒**自动中断并提示超时
- **测试用例**：
  - [保存为用例]：把当前一组填值命名保存
  - 用例下拉列表：选中后一键回填所有输入框，再点运行即可重跑
  - 可删除用例

#### 4.3.4 AI 对话面板

- **一条规则固定一个会话**（规则创建时自动建立，无会话列表、不能新建/删除会话）
- 每次发消息，自动把**当前编辑器中的脚本内容**一并作为上下文发给大模型
- **流式输出**（打字机效果）
- 大模型回复中若包含完整脚本代码块，提供 **[应用到编辑器]** 按钮
- [清空对话]：清除该会话的记忆和历史消息
- 打开页面时加载历史消息回显

## 5. 交互规则汇总

| # | 规则 |
|---|---|
| 1 | 未校验或校验未通过，运行按钮锁定不可点 |
| 2 | 脚本内容一旦被修改，校验结果作废，运行按钮重新锁定，必须重新校验 |
| 3 | 校验、运行、AI 对话、AI 审查一律使用编辑器当前内容（含未保存修改） |
| 4 | 校验为大模型 CR 同步等待，全部完成后才解锁运行 |
| 5 | AI 审查意见为建议性质，不强制阻断运行 |
| 6 | 删除规则必须二次确认 |

## 6. 非功能要求

| # | 要求 | 说明 |
|---|---|---|
| 1 | 服务稳定 | 用户脚本写错、死循环、危险操作，都不能把工具本身搞挂 |
| 2 | 执行限时 | 单次脚本执行最长 5 秒，超时自动中断并提示 |
| 3 | 危险操作拦截 | 脚本中访问文件、访问网络、终止进程、起线程等危险行为必须被拦截并提示 |
| 4 | 错误可读 | 所有返回给用户的错误必须是可读的中文提示，不出现原始堆栈 |
| 5 | 对话持久 | 聊天记录重新打开页面后仍可查看；服务重启后历史消息不丢 |

## 7. 验收清单

**规则列表页**
- [ ] 能新建规则（名称 + 描述），创建后自动进入工作台
- [ ] 列表展示名称、描述、更新时间，支持分页
- [ ] 支持按名称模糊搜索
- [ ] 能改名、改描述
- [ ] 删除有二次确认，删除后其会话、消息、测试用例一并清除

**工作台 — 编辑与校验**
- [ ] 编辑器有 Groovy 语法高亮和行号，支持手动保存
- [ ] 语法错误：展示行号 + 原因，编辑器对应行标红，运行按钮锁定
- [ ] 校验后列出所有占位符及其类型
- [ ] 大模型审查期间显示加载状态，返回后展示审查卡片
- [ ] 审查给出修改脚本时可一键应用到编辑器
- [ ] 语法通过且审查返回后，运行按钮解锁
- [ ] 修改脚本内容后，运行按钮重新锁定

**工作台 — 运行**
- [ ] 占位符表单按类型渲染（数字框 / 布尔下拉 / 文本框），格式错误前端拦截
- [ ] 运行后展示返回值
- [ ] 死循环脚本 5 秒后中断并提示超时
- [ ] 危险脚本（如访问文件）被拦截并给出可读提示
- [ ] 能保存测试用例、一键回填重跑、删除用例

**工作台 — AI 对话**
- [ ] 打开页面自动回显历史消息
- [ ] 发消息流式输出（打字机效果）
- [ ] 多轮对话大模型记得前文
- [ ] 回复中的脚本代码块可一键应用到编辑器
- [ ] 清空对话后记忆与历史消息均被清除
