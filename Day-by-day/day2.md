# Day 2（2026-09-01）：需求定稿 + 文档拆分 + 仓库上云

## 做了什么

- 通过多轮问答把需求从零敲定：脚本只支持 Groovy、占位符用 `${变量名}`、校验必须同步等大模型审查返回、一条规则一个会话、接口全部 POST
- 把混合的 PRD 拆成《需求文档》《技术方案》两份独立文档
- 做了三套 UI 风格稿（浅色商务 / 深色代码风 / 现代渐变），本地起预览服务对比后，选定"风格三：现代渐变风"
- 初始化 git 仓库，按作业模板补齐 README、`.qoder/rules/` 规则、JOURNAL 骨架，推送到 GitHub

## 卡在哪

- 推送 GitHub 一直报 `Error in the HTTP2 framing layer`：排查发现本机网络只放行 `api.github.com` 和 `codeload.github.com`，github.com 主站不通。配置 Clash 代理（127.0.0.1:7897）后推送成功，中间还有一次是纯网络抖动，重试即过
- 本机环境坑：`python3` 因缺 Xcode CommandLineTools 报错不可用；`node` 未安装（前端开发前需要补装），临时用系统自带的 ruby 起了静态预览服务

## 怎么解开的

- 网络问题：逐个通道探测（主站 / api / codeload / git 智能接口）定位到"主站被限"，再用代理解决，而不是盲目重试
- 环境问题：逐个 `which` 排查可用工具，找到替代路径
